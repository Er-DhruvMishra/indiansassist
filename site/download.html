Download

IndiansAssist connects a technician (the Assist console, in a browser) with the computer or phone being helped (the Desk). The Desk can join from a browser with nothing installed; the agents and apps below add remote control, unattended access to managed devices and mobile screen sharing.

Getting help from a technician? You usually do not need this page. Open the link or code your technician gave you; the join page of your organisation's IndiansAssist server offers the right file for your device, and it only works with that server.

All files are published on GitHub Releases, built by GitHub Actions from the public source, together with a SHA256SUMS file. Self-hosting operators publish the same files on their own server (see docs/release.md in the repository).

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Current status: the SignPath Foundation certificate has not been granted yet. Releases are currently signed with the project's own self-signed certificate (Windows) and GPG key (Linux). The SignPath arrangement applies once the project is approved. Because the Windows certificate is self-signed, Windows SmartScreen and the UAC prompt show an unknown publisher until then.

macOS, iOS and Android builds are outside SignPath's scope. The macOS files are signed ad hoc only until the project has an Apple Developer ID; then they will be signed and notarized. Until then macOS asks you to allow the app in System Settings, Privacy & Security.

The full code signing policy lists the team roles and the manual approval of every release.

Verify a download

The public keys are published under /keys/ on this site and in the repository under site/keys/:

  • indiansassist-windows-selfsigned.cer: the Windows code signing certificate (self-signed, interim).
  • indiansassist-release-signing.asc: the OpenPGP key that signs the Linux files and SHA256SUMS.

Fetch each key from both places and check that they are the same file.

Checksums (every platform)

# Linux and macOS
sha256sum -c SHA256SUMS --ignore-missing      # macOS: shasum -a 256 -c SHA256SUMS --ignore-missing

# Windows PowerShell: compare with the line for the file in SHA256SUMS
(Get-FileHash .\IndiansAssist-windows-x64-<version>.exe -Algorithm SHA256).Hash

Windows signature

$sig  = Get-AuthenticodeSignature .\IndiansAssist-Agent-<version>-windows-x64.msi
$cert = New-Object System.Security.Cryptography.X509Certificates.X509Certificate2 .\indiansassist-windows-selfsigned.cer
$sig.SignerCertificate.Thumbprint -eq $cert.Thumbprint    # True
$sig.TimeStamperCertificate -ne $null                     # True: timestamped

While the certificate is self-signed, the signature status is UnknownError (untrusted root). That is expected; you do not need to install the certificate anywhere.

Linux signatures

gpg --import indiansassist-release-signing.asc
gpg --verify SHA256SUMS.asc SHA256SUMS
gpg --verify IndiansAssist-Agent-<version>-linux-x64.deb.asc IndiansAssist-Agent-<version>-linux-x64.deb
sudo rpm --import indiansassist-release-signing.asc
rpm -K IndiansAssist-Agent-<version>-linux-x64.rpm
