Remote support that people can trust

IndiansAssist is an open source remote support and remote access platform. A technician helps someone over their screen, with that person's consent, from a browser. Every session is recorded in a tamper-evident audit chain, and an organisation's data stays in the region it chooses. You can run it on your own servers.

Download Source code on GitHub

What it does

Help from the browser

The person being helped (the Desk) opens a join link and shares a screen or a tab. The technician (Assist) sees it in the web console, with voice, chat, file transfer and on-screen annotation. Nothing to install for a quick session.

Remote control with consent

Small native agents for Windows, Linux (X11 and Wayland) and macOS, an Android app and a browser extension give the technician control when the person agrees. The consent screen says exactly what will be shared, and a visible indicator stays on screen for the whole session.

Managed devices

Installed agents for Windows, Linux and macOS let an organisation support its own fleet: unattended access under a policy, consent receipts, playbooks, remote wake and device groups.

A record you can verify

Each organisation has an append-only, hash-chained audit log with signed checkpoints. Recordings, when turned on, are stored with their SHA-256 in the chain, and the console verifies the chain and each recording.

Data residency and privacy

An organisation picks India, the EU or the US at sign-up and its data stays there. Personal values in the audit chain are stored only as keyed hashes; an organisation can erase itself completely. See the privacy policy.

Built for teams

Roles, single sign-on (OIDC and SAML), branding, a phone layout for the console, optional AI session summaries (off by default) and ticketing integrations for Zoho Desk, ServiceNow, Jira, Freshdesk and webhooks.

Open source

IndiansAssist is free software under the GNU Affero General Public License, version 3 only. The whole project, the server, the web app, the agents and the apps, is developed in public at github.com/Er-DhruvMishra/indiansassist. Releases are built from that source by GitHub Actions.

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Current status: the SignPath Foundation certificate has not been granted yet. Releases are currently signed with the project's own self-signed certificate (Windows) and GPG key (Linux). The SignPath arrangement applies once the project is approved.
